Cloud Architecture

From parking slot → cloud → decision

A simple architecture keeps the prototype feasible while leaving room to scale.

Cloud Pipeline IDLE • Waiting for next sensor event
STAGE 01
DATA IN IoT / Gateway

Parking slot sensors via IoT / Gateway detecting ultrasonic distance and vehicle magnetic flux.

  • Ultrasonic Sensor Node (HC-SR04 / ESP32)
  • MQTT / HTTPS Ingestion Protocol
  • Battery & Solar Voltage Telemetry
STAGE 02
PROCESS API Gateway + Lambda

Logic layer validating sensor signature, computing slot state deltas, and triggering broadcast events.

  • Amazon API Gateway (REST / WebSocket)
  • AWS Lambda Event Handler (Python/Node)
  • State transition & debounce filter
STAGE 03
DECISION OUT DynamoDB → Dashboard

DynamoDB stores time-series history + active state, streaming instant decisions to driver dashboards.

  • Amazon DynamoDB (Current Occupancy Table)
  • Historical analytics & peak prediction model
  • Real-time Web App Dashboard (User view)
